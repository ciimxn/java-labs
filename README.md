# Лабораторные работы по дисциплине «Основы кроссплатформенного программирования» (Java)

Студент: Мельник Дмитрий
Вариант: 14

## Содержание репозитория
- `lab10` — Разработка классов с интерфейсами (Интерфейсы Connectable, Configurable; классы Computer, Router).
- `lab11` — Полиморфизм (Базовый класс Building, наследники Residential, Office; перегрузка и переопределение методов).
- `lab12` — Обобщенные типы и коллекции значений (Задание 1: Garment/Jacket/TShirt/Pants в Map; Задание 2: Programmer в List с фильтрацией, повышением уровня и сортировкой).
- `lab13` — Обработка исключительных ситуаций (Сущность Transport, пользовательские исключения InvalidTransportDataException, TransportNotFoundException, MaintenanceException, автопарк Fleet).
- `lab14` — Файловый ввод и вывод (5 заданий варианта 14: любимая еда, ввод 10 чисел и подсчет нечетных, фильтрация случайных чисел с цифрой 5, расчет среднего объема из 15 значений, подсчет чисел в диапазоне от -50 до 50).
- `lab15` — Система управления версиями Git и работа с GitHub (перенос лабораторных работ в единый репозиторий через ветки и merge-коммиты).
